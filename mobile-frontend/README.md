# Mobile Frontend

This directory is reserved for future mobile application development using Jetpack Compose.

The mobile app will target Android and iOS platforms for the ISET Tozeur Digital Observatory.

## Planned Features
- Student portal access
- Survey response submission
- Alumni profile management
- Push notifications

## Tech Stack (Planned)
- Kotlin
- Jetpack Compose
- Material Design 3
- Retrofit for API communication
- Jetpack Navigation
